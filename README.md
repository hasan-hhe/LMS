# LibraLMS

نظام إدارة مكتبة متكامل: استعارة وحجوزات وغرامات + بيع بالنقاط. Laravel 12 / PHP 8.2 / MySQL / Sanctum.

التقرير الأكاديمي: [`docs/تقرير_نظام_إدارة_المكتبة_الموحد.md`](docs/تقرير_نظام_إدارة_المكتبة_الموحد.md)

## الأسطح

| السطح | المسار | من يستخدمه |
|--------|--------|-------------|
| Dashboard API | `/api/v1/*` عبر `routes/dashboard.php` | لوحة الويب + تطبيق الأمين |
| App API | `/api/v1/*` عبر `routes/api.php` | تطبيق العضو |
| لوحة الإدارة | `/admin` | Blade + Axios |

الأدوار: `ADMIN` · `LIBRARIAN` · `MEMBER`. عمود كلمة المرور: `password_hash`.

## التشغيل

```bash
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
php artisan schedule:work
```

بعد الـ seeder:

| الدور | البريد | كلمة المرور |
|--------|--------|-------------|
| مدير | `admin@lms.test` | `password` |
| أمين | `librarian@lms.test` | `password` |
| عضو | `member1@lms.test` | `password` |

لوحة الإدارة: `/admin/login`

المهام المجدولة: غرامات يومية (`fines:accrue-daily` الساعة 00:10)، انتهاء الحجوزات والطلبات غير المستلمة كل ساعة، تذكير الاستحقاق الساعة 08:00.

## قواعد التشغيل المعتمدة

- مخزون البيع = `books.amount`. نسخ الإعارة = `book_instances` ولا تُباع.
- استعارة نشطة واحدة لكل عضو. التسجيل الفيزيائي لأمين المكتبة فقط.
- الحجز على نسخة متاحة فقط. الاستلام ينشئ استعارة ويخصم `borrow_points` إن وُجدت.
- التمديد مرة واحدة بالنقاط. أمين المكتبة يمكنه تمديداً إدارياً بدون نقاط.
- الغرامة اليومية تُحسب ليلاً وتُسقف بسعر الكتاب. الإتلاف/الفقد = بدل الكتاب ويعفي غرامة التأخير غير المدفوعة.
- الطلب: `pending` → `confirmed` (خصم نقاط ومخزون بيع + مهلة 48 ساعة) → `delivered`. الإلغاء بعد التأكيد يعيد النقاط والمخزون.
- عضوية الإعارة عبر `participe_end_date`؛ الاشتراك بالنقاط من التطبيق (`membership_points` / `membership_days`).
- الدفع داخل التطبيق بالنقاط. أمين المكتبة يمكنه تحصيل الغرامة نقداً.
